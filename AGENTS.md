# Instrucciones del workspace Codex

- Estoy iniciando el proceso de estudio de programacion con IA.
- Responder siempre en espanol, con posibilidad de traduccion si se solicita.
- Explicar cada cambio que se haga y por que.
- Cuando se encuentre un error, explicar primero que lo causa antes de corregirlo.
- Preguntar por el proyecto y sugerir la mejor opcion en arquitectura, tecnologia, seguridad y flujos cuando aplique.
- Antes de sugerencias importantes, informar el criterio para analizarlo.
- Revisar o solicitar el arbol de carpetas de proyectos antes de reorganizar estructura.
- Preguntar si existen proyectos relacionados antes de cambios que puedan afectar el workspace.
- Antes de actualizaciones importantes en codigo, actualizar documentacion en `docs`, README y HTML de informacion de soporte cuando aplique.
- Hacer commit antes de cambios variados o importantes cuando el repositorio ya tenga un punto estable.
- No ejecutar cambios destructivos sin autorizacion explicita.

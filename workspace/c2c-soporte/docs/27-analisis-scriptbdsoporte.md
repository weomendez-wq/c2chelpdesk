## Observaciones tecnicas

### Secuencias no incluidas

El script usa `nextval('rr_gestion_soporte.<tabla>_id_seq'::regclass)`, pero no crea explicitamente esas secuencias.

En una base limpia puede fallar al crear las tablas si las secuencias no existen.

Decision de normalizacion:

```txt
Usar GENERATED BY DEFAULT AS IDENTITY
```

### Idempotencia parcial

El script usa `CREATE TABLE IF NOT EXISTS`, pero los `ALTER TABLE ... ADD CONSTRAINT` no tienen proteccion contra constraints ya existentes.

En una segunda ejecucion puede fallar por constraints duplicadas.

Decision de normalizacion:

```txt
Crear FKs dentro de bloques DO que validen pg_constraint antes de agregar.
```

## Decision de implementacion

No ejecutar el script original tal cual.

Crear una version normalizada con prefijo `helpdesk_`, conservando las ideas utiles del script original y agregando los campos operacionales del proyecto C2C.

Archivos propuestos:


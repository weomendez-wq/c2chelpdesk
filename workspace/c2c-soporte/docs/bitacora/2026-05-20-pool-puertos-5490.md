# Bitacora: pool de puertos 5490

**Fecha**: 2026-05-20

## Contexto

Se define que `c2c-soporte` debe partir desde el puerto `5490` y reservar una
decena completa para evitar conflictos con otros proyectos locales.

## Cambios realizados

- Frontend Vite: `5490`.
- Backend API: `5491`.
- PostgreSQL local soporte: `5492`.
- Proxy frontend `/api`: `http://localhost:5491`.
- `DATABASE_URL` de ejemplo: `postgres://postgres:postgres@localhost:5492/soporte`.
- Orquestador actualizado para marcar el pool `5490-5499` como asignado a
  `c2c-soporte`.

## Pendiente operativo

Confirmar que PostgreSQL local efectivamente escuche en `5492` antes de probar
el backend. Si el cluster aun escucha en otro puerto, se debe migrar o levantar
una instancia local dedicada en `5492`.
